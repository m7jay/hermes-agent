Privacy Policy

Hermes Agent — last updated 23 October 2026

Hermes Agent ("the application") is a private, single-user tool operated by its owner. This policy explains what Google user data it accesses, why, and what happens to it.

How data is stored

Data is processed and stored only on the owner's own machine. OAuth refresh tokens are kept in a local file readable solely by the owner's operating-system account. Messages, files and documents are fetched on demand and are not retained in any external database.

Sharing

Google user data is not sold, rented, transferred or disclosed to any third party, advertiser, or data broker. It is not used to train machine-learning models, and it is not used for advertising or profiling of any kind.

Model processing

When the owner asks the application to perform a task, the minimum content required for that task (for example, the text of a single email) may be sent to the language-model provider the owner configured. That transfer happens only on the owner's explicit request, only for the data needed to answer it, and is not retained by this application.

Limited Use disclosure. Hermes Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion

The owner can revoke this application's access at any time at myaccount.google.com/permissions. Deleting the local token file (google_token.json) removes all stored credentials from the machine. Because no Google data is held anywhere else, revocation and deletion are immediate and complete.

Children

This application is not directed at children and is not made available to any other user.

Changes

Material changes to this policy will be reflected in the "last updated" date above.
